# Checkpoint Alerts

Sobriety checkpoints, mapped from official law-enforcement announcements.
Ohio is the current coverage area.

The map lives at
[ohiocreditaudit.github.io/checkpoint-alerts-site](https://ohiocreditaudit.github.io/checkpoint-alerts-site/).
`checkpoints.geojson` is the data behind it, refreshed as agencies publish —
every checkpoint traces to a public announcement by the agency that ran it,
and nothing is user-reported.

Locations are only as precise as the announcement: an address is a pin, a
stretch of road is a line, and a vague announcement is drawn wide and marked
low-confidence rather than pretending to a doorstep.
